# SIP (Simple Interface Pages)

Професійні landing pages для кав'ярень, ресторанів та локальних закладів.

## Value Proposition
Ми створюємо сучасні, адаптивні та конверсійні сайти для локальних бізнесів. Наша мета — дати закладу професійне онлайн-представництво за лічені хвилини.

## Публічний доступ (GitHub Pages)
Після активації GitHub Pages у налаштуваннях репозиторію, проєкти будуть доступні за посиланнями:
- **Демо-сайт La Cafe**: [https://yurii747-bit.github.io/sip-sites/la-cafe/](https://yurii747-bit.github.io/sip-sites/la-cafe/)
- **Універсальний шаблон**: [https://yurii747-bit.github.io/sip-sites/template-cafe.html](https://yurii747-bit.github.io/sip-sites/template-cafe.html)

## Склад репозиторію
- `la-cafe/`: Приклад повністю готового сайту для кав'ярні "La Cafe".
- `template-cafe.html`: **Основний інструмент.** Універсальний шаблон з JavaScript-конфігурацією. Дозволяє швидко змінювати дані закладу в одному місці.
- `templates/`: Додаткові варіанти дизайну та статичні шаблони.
- `scripts/`: Скрипти для відділу продажів та роботи з клієнтами.
- `leads.json`: База потенційних клієнтів.

## Як користуватися універсальним шаблоном
1. Відкрийте `template-cafe.html`.
2. На початку файлу знайдіть об'єкт `CONFIG`.
3. Змініть назву, адресу, телефон, години роботи та кольори на потрібні.
4. Сторінка автоматично оновить весь контент, мета-теги та посилання.
