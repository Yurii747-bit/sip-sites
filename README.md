# SIP (Simple Interface Pages)

Професійні landing pages для кав'ярень, ресторанів та локальних закладів, які не мають вебсайту.

## Value Proposition
Готові преміальні сайти під ключ. Клієнт отримує сучасний, адаптивний та конверсійний сайт, який допомагає залучати клієнтів з онлайну.

## Склад репозиторію
- `la-cafe/`: Демо-сайт для кав'ярні "La Cafe". Доступний за адресою [https://yurii747-bit.github.io/sip-sites/la-cafe/](https://yurii747-bit.github.io/sip-sites/la-cafe/)
- `template-cafe.html`: Універсальний шаблон кав'ярні з JS-конфігурацією для швидкого запуску нових об'єктів.
- `templates/`: Колекція статичних шаблонів.
- `leads.json`: База потенційних клієнтів (результати дослідження ринку).
- `scripts/`: Скрипти холодних дзвінків та варіанти комунікації для відділу продажів.

## Як швидко запустити новий сайт
1. Відкрийте `template-cafe.html`.
2. Відредагуйте об'єкт `CONFIG` на початку файлу (назва, адреса, телефон, години, кольори).
3. Збережіть та розгорніть!
