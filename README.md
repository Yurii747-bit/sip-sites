# SIP (Simple Interface Pages)

Професійні landing pages для кав'ярень, ресторанів та локальних закладів.

## Склад репозиторію
- `la-cafe/`: Приклад готового сайту для кав'ярні "La Cafe".
- `templates/`: Колекція шаблонів для швидкого старту.
- `template-cafe.html`: Універсальний шаблон кав'ярні з JS-конфігурацією.
- `leads.json`: Список потенційних клієнтів (результати дослідження).
- `call_script.md`: Скрипт холодного дзвінка для продажів.
- `call_scripts_variants.md`: Варіанти скриптів під різні типи закладів.

## Як використовувати шаблон `template-cafe.html`
Відкрийте файл та змініть об'єкт `CONFIG` на початку файлу. Всі зміни автоматично відобразяться на сторінці.
