# SIP Coffee Shop Template

Цей шаблон призначений для швидкого створення преміальних лендінгів для кав'ярень та невеликих закладів харчування.

## Файли
- `universal-coffee.html` — основний шаблон.

## Як користуватися
1. Скопіюйте вміст `universal-coffee.html` у новий файл (наприклад, `index.html` для вашого клієнта).
2. Використовуйте функцію "Find & Replace" у вашому редакторі коду, щоб замінити змінні в подвійних фігурних дужках `{{ VARIABLE }}` на реальні дані закладу.

### Список основних змінних:
- `{{BUSINESS_NAME}}` — Назва закладу (напр. "Black Wood Coffee")
- `{{BUSINESS_LOGO_NAME}}` / `{{LOGO_SUFFIX}}` — Для стилізованого лого (напр. "Black" та "Wood")
- `{{CITY}}` — Місто
- `{{SLOGAN}}` — Короткий слоган
- `{{PHONE_LINK}}` — Номер телефону у форматі `+380...` (без пробілів)
- `{{PHONE_DISPLAY}}` — Номер телефону для відображення
- `{{LOCATION_SHORT}}` — Коротке розташування (напр. "Центр, Львів")
- `{{FULL_ADDRESS}}` — Повна адреса
- `{{HOURS}}` — Години роботи (напр. "Щодня: 08:00 – 21:00")
- `{{HERO_TITLE}}` / `{{HERO_SUBTITLE}}` / `{{HERO_DESCRIPTION}}` — Контент головного екрану
- `{{GOOGLE_MAPS_EMBED_URL}}` — Посилання для iframe карти (отримайте через Google Maps Share -> Embed map)

## Налаштування дизайну
Вгорі файлу в секції `:root` ви можете змінити кольори:
- `--primary`: Основний темний колір (зазвичай для фону hero або тексту)
- `--accent`: Акцентний колір (кнопки, іконки)
- `--bg`: Основний фон сторінки

## Особливості
- **Mobile First**: Ідеально працює на смартфонах.
- **Scroll Reveal**: Анімація елементів при прокрутці.
- **Micro-interactions**: Плавні ховер-ефекти та переходи.
- **Performance**: Один файл, мінімум зовнішніх запитів (тільки Google Fonts).
